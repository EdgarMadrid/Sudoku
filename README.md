## 📌 Descripción

Este proyecto es una implementación del clásico juego **Sudoku** desarrollado con **HTML, CSS y JavaScript Vanilla**.

El objetivo principal es practicar lógica de programación, manipulación del DOM y estructuración de proyectos frontend sin frameworks.

## 🧠 Cómo funciona el juego

El usuario interactúa directamente con un tablero 9x9.

El sistema valida las reglas clásicas del Sudoku:

- No se pueden repetir números en una fila
- No se pueden repetir números en una columna
- No se pueden repetir números en una subcuadrícula 3x3
